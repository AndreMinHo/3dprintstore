# 3D Print Storefront
Express.js/SQLite project for the HarvardX CS50's Introduction to Computer Science final project.

This is a storefront where you can buy different 3D printed products available in a catalogue. The main feature is being able to customize your order by chosing what filament will be used by the 3D printer.  
  
## Prerequisites:

- Node.js (v18+ recommended)
- npm (comes with Node.js)

## Usage:
To seed a placeholder database run:  
`node seed.js`

To start a server:  
`npm start`

Open the app in your browser:  
`http://localhost:3000`
